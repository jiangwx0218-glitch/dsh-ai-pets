# DSH AI Pets · Windows 独立版

给 Windows 用的桌宠：**GPT / Claude / Gemini** 三只，装完就能在桌面上待机、张望、被拖来拖去，还能在桌宠身上右键打开菜单。

这是**独立的小程序**，跟 DSH 没关系——不用装 DSH，不用装 Node，也不用联网下载宠物素材。安装包里已经把三只宠物和运行时都带好了，装完双击就能跑。

> 想把宠物装进 DSH 里当插件，看的是另一份文档：[README.md](README.md)。

## 装之前

- **系统**：Windows 10 或 Windows 11，**64 位**。
- **不需要**：Node、DSH、管理员权限。
- 安装包是一个 exe：`dsh-pet-Setup.exe`。

## 安装

双击 `dsh-pet-Setup.exe`，跟着向导点下一步，没有需要你填的东西。

> 首屏 Windows 会先拦你一下，见下一节。

装完**开始菜单**和**桌面**各有一个 `dsh-pet` 快捷方式。

默认装在 `%LOCALAPPDATA%\dsh-pet`，展开就是 `C:\Users\<你的用户名>\AppData\Local\dsh-pet`。装在用户目录下，所以全程**不需要管理员权限**，也不往 `Program Files` 里写东西。想换位置，向导里可以改。

## 第一次运行：Windows 会弹「已保护你的电脑」

第一次双击，大概率先看到蓝色的 **「Windows 已保护你的电脑」**（Microsoft Defender SmartScreen）。

它不是病毒提示。它的意思是「这个 exe 没有数字签名，我（Windows）不认识它」。

过去的方法：

1. 点提示框里的 **「更多信息」**——默认是折叠的，不点开看不到下面那个按钮；
2. 点出现的 **「仍要运行」**。

然后就正常启动了，同一份安装包之后不会再拦。

### 为什么会有这道提示，为什么我们不去掉它

Windows 对每个从网上下载的 exe 看两件事：有没有可信的**代码签名**，以及这个程序被多少人用过、有没有积累出信誉。我们这个安装包两头都不占——没有签名证书，也没有那份信誉。

要彻底消掉它，正规路子只有一条：买一张代码签名证书（每年要花钱，还要过实名/资质审核），然后给安装包签名。这是一个免费、开源的项目，里面的美术素材还是 CC BY-NC-SA（**禁止商用**）的，为它买证书签名我们没做这个投入。

所以**这道提示会一直在，我们也给不了你一个「不弹它」的版本**。能做的只有把话说清楚：

- 确认这个 exe 是从本仓库的 Release 页面下载的，那就按上面两步点过去；
- **如果你不确定这个 exe 从哪来的，别点「仍要运行」**——这道提示存在的意义，就是拦住这种事。

## 它能做什么，不能做什么

先说一件最容易误解的事：**独立版不装 DSH 也能自己干活**。

装完默认是「什么都不配」的状态，这时它只有动画和拖拽。想要更多，在桌宠身上右键，菜单第一项是 **「打开 AI 设置」**，会把本机的**桌宠设置**页开在你的浏览器里（地址是本机，不联网也能打开）。在那儿填一个 AI 服务商的密钥、选好对话模型，下面这几样就能用：

- ✅ **查看余额**——菜单里的「查看余额」按你填的密钥去查真实额度；
- ✅ **碎碎念**——配好模型后它会自己说点什么；
- ✅ **对话**——菜单里的「对话」能真的聊，回复在气泡里显示；
- ✅ **系统通知**——对话完成、生成失败这类事件会弹通知，设置页里能关。

**这四样都依赖你自己配的那个密钥**，不配就没有——不是坏了。用它们要联网。

真正的边界在这儿：

- ❌ **不知道你在干什么**——它读不到 DSH 的项目、会话和代码，所以没有「工作状态联动」这类东西；
- ❌ **没有 DSH 的账号体系**——DSH 账号里的额度统计、插件生态里那些功能用不了。

不需要任何配置就有的：

- ✅ **动画**——待机呼吸、左右张望、被拖起来手脚乱蹬、点一下有反应，每只几十到一百多个动作；
- ✅ **拖拽**——随手拖到桌面任意位置；
- ✅ **右键菜单**——在桌宠身上右键，从上到下是：打开 AI 设置 / 查看余额 / 查询天气 / 待办事项 / 碎碎念 / 对话 /（配图）（睡觉），然后是 **「动作」** 分类树，最后是 显示位置 / 重载配置 / 回到初始位置。带括号的两项不一定出现：没配表情包就没「配图」，素材里没有睡觉动作就没「睡觉」。
- ✅ **「动作」树里的分类**——待机、转向、拖拽、点击回应、移动，再加 吃什么、时节、小动作、玩耍、才艺表演、娱乐休闲、魔法特效、工作职业、吃喝、日常起居、情绪反应、运动健身、换装造型、礼仪致意、龙族特性、模仿动物 等（三只宠物分类不完全一样，每类下面才是具体动作）；
- ✅ **换宠物、同时显示多只**——在托盘图标右键的菜单里勾选。

一句话：装上就是**桌面挂件**；愿意配个密钥，它才变成会说话的那只。

## 换宠物

三只（GPT / Claude / Gemini）在安装时就已经都在本地，不需要另外下载。

换宠物在**系统托盘**上：任务栏右下角的通知区域里找到桌宠的托盘图标，在它上面**右键**，菜单里会列出 **GPT / Claude / Gemini**。

菜单里每一项前面是个勾选框，**打勾表示这只显示在桌面上**：

- 想让它出现在桌面上：勾上；
- 想收起来：取消勾选；
- **可以同时勾多只**——三只一起待在桌面上也行，每一只是独立的窗口，可以分开拖到不同位置。

（注意：程序同一时间只能跑一个，重复双击快捷方式不会开出第二份。想看多只，就用上面这个办法勾。）

菜单里还会有第 4 项 **「蓝毛小女仆」**——那是程序自带的默认宠物，不在我们这三只里。想看她也可以勾上。

如果托盘图标被 Windows 折叠进了 **「^」** 那个小箭头里，先点开箭头，再在那个图标上右键。

菜单里每一项具体叫什么，我们没在 Windows 上逐条核对过文案——认准 **GPT / Claude / Gemini** 这三个名字就对了。

## 卸载

两种方式，效果一样：

1. **设置 → 应用 → 已安装的应用**，找到 **「dsh-pet 桌面版」**，点「卸载」；
2. 进安装目录（默认 `%LOCALAPPDATA%\dsh-pet`），运行里面的卸载程序。

卸载会删掉**安装目录**和**开始菜单、桌面的快捷方式**。

宠物数据是单独放的，不在安装目录里——三只宠物的配置和动画大约 **394MB**，在 `%USERPROFILE%\.dsh\dsh-pet` 下。所以卸载过程中会**问你一次**，大意是这样：

> 是否一并删除宠物数据？
>
> `%USERPROFILE%\.dsh\dsh-pet`（约 394 MB：三只宠物的配置与动画）
>
> 如果这台机器上还装着 DSH 插件版桌宠，它用的是同一个目录，请选「否」。

- 选 **「是」**：连宠物数据一起清干净，这台机器上不留东西；
- 选 **「否」**：宠物数据留着，安装目录和快捷方式照删。这台机器上还装着 DSH 插件版桌宠时选这个——两边用的是同一个目录，一起删掉会把插件版那边也弄坏。

静默卸载（不弹窗、带参数跑的那种）不会动宠物数据。

## 装完没反应、宠物不见了

**双击后什么都没发生**
先确认是不是被拦住了但没注意到——SmartScreen 的窗口、托盘和右下角通知都可能出现在别的显示器上。另一个可能是杀毒软件直接把 exe 删了，去隔离区看一眼。

**宠物不见了**
先看托盘：右键托盘图标，看那只宠物的勾还在不在——取消勾选就会从桌面上收起来，重新勾上就回来。也可能是从开始菜单或桌面的 `dsh-pet` 快捷方式重开时没启动起来。桌宠窗口没有标题栏，被拖到屏幕边缘、拖到屏幕外或者落在另一块显示器上时，看着也像「消失了」——先把所有屏幕扫一遍。

**想同时看到多只宠物**
程序同一时间只能跑一个——重复双击快捷方式，第二次启动会自己退出，不会再多一份。想同时看到多只，用托盘菜单把想看的几只都勾上，每只是独立的窗口，可以分开拖到不同位置。
